# Titanic Dataset Analysis

## Project Overview
This project focuses on analyzing the Titanic dataset using Python. The main aim is to understand passenger characteristics and explore survival patterns based on passenger class, gender, age, fare, and other factors. I performed data cleaning and Exploratory Data Analysis (EDA) to explore the dataset and identify useful insights through visualizations.

## Objectives

- Understand the distribution of passengers by survival status.

- Analyze survival patterns based on gender and passenger class.

- Explore the age and fare distributions of passengers.

- Compare survival rates across different passenger classes and embarkation points.

- Examine fare and age distributions across passenger classes.

- Identify useful patterns through data visualization.

## Tools and Technologies

- Python (Jupyter Notebook)

- Pandas and NumPy for data manipulation and preprocessing

- Matplotlib and Seaborn for data visualization

## Dataset

The dataset contains passenger information such as survival status, passenger class, name, gender, age, family members aboard, ticket number, fare, cabin, and embarkation point.
